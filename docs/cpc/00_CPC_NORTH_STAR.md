# CPC North Star

Version 1.0

CPC helps EA SPORTS FC Clubs players and clubs find each other, commit to playing, and build a trustworthy reputation.

Core loop: Need -> Discover -> Match -> Commit -> Play -> Prove -> Repeat.

The primary outcome is a successful playable connection between a player and a club.

Core pillars: LIVE discovery, precise formation-slot recruiting, trust and reliability, commitment and check-in, CPC identity, and club operations.

Product rules:
- Mobile-first and fast.
- One obvious primary action per screen.
- Sensitive state transitions are server-authoritative.
- Trust cannot be purchased.
- PRO can improve convenience and limits but cannot manufacture reputation.
- CPC-derived ratings must never be presented as official EA ratings.
- Social features remain secondary to the recruiting and play loop unless the product owner explicitly changes this priority.

V1 is not a replacement for EA SPORTS FC, an official EA companion app, a FUT marketplace, a streaming platform, or a generic social network.

Golden rule: a feature is core only if it improves discovery, commitment, trustworthy evidence, or club operations.
